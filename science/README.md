# Scientific account

How accurately can a noisy physical register be initialized when entropy can leave only through selected reset contacts?

The result is an exact geometry-dependent lower bound for arbitrary local coherent control, with matching order for every contact placement on a chain and for slabs cooled from a full face. Every physical qubit is retained, and initialization includes removal of input-reference correlations.

Read in this order:

1. [Model and main statements](model.md): operations, independent noise, output convention, complete-channel error and scope.
2. [Causal converse](converse.md): the surviving tracial-qubit factor, terminal noise count and duration-independent bound.
3. [Geometry and constructions](geometry.md): exact SWAP replacement channel, fixed path contacts, optimal placement and cooled-face slabs.
4. [Physical interpretation](interpretation.md): register size, spread versus clustered contacts, and dimensional scaling.
5. [Noise and task boundaries](noise_and_scope.md): a mixed-unitary extension, target-preserving counterexamples and physical-output requirements.

[Related work](../references/RELATED_WORK.md) credits prior one-port cooling and transport constructions. [Verification](../verification/README.md) documents finite channel calculations, reference-sensitive tests, trajectory checks and their limits.
